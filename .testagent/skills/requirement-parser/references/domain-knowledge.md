# 领域知识参考

供 requirement-parser 解析需求文档时参考的术语与缩写。各团队可按自身产品补充或替换本文件内容。

## 需求层级前缀

| 前缀 | 全称 | 含义 |
|------|------|------|
| IR | Initial Requirement | 初始需求 |
| SR | System Requirement | 系统需求 |
| US | User Story | 用户故事 |
| FuR | Functional Requirement | 功能需求 |
| AR / AREQ | Allocation Requirement | 分配需求 |
| FUNC | Function module tracking | 功能模块跟踪 |

## 常见模块缩写

| 缩写 | 全称 | 含义 |
|------|------|------|
| UPCF | User Plane Control Function | 用户面控制功能 |
| PMS | Policy Management Service | 策略管理服务 |
| PES | Policy Engine Service | 策略引擎服务 |
| DLB | Diameter Load Balance | Diameter 分发服务 |
| HLB | HTTP Load Balance | HTTP 分发服务 |

## 说明

- 需求文档可能使用中文术语，需求编号遵循特定模式但可能存在变体
- 非功能需求通常包含量化指标（如恢复时长、端到端时延等）
- 本 skill 同时支持中文与英文需求文档
